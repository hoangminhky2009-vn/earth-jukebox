# How we used SI (Super Intelligence / AI)

We used **Claude** (Anthropic, through Claude Code) as a coding and writing assistant, and **OpenAI Codex** for the data pipeline. Every file made with either says so in its first line.

- **Where:** Claude wrote most of the JavaScript in `docs/js/` (the page, the pixel scene, the music engine and its tests), the sound-cutting script and the note-checking script in `tools/`, and the notes and documents. OpenAI Codex helped Sabik write and test the Python data pipeline in `pipeline/` that reads colours from NASA SVS frames.
- **What we did ourselves:** Bormey chose the four river places and wrote their introductions and sources. Ky gave the sampling coordinates, decided the look (a pixel jukebox, approved from art samples before it was built), chose the final sound by listening to six versions side by side, and decided to add a forest, a desert and a snow place; Claude proposed the exact spots (Amazon near Manaus, Alice Springs, Tromso) after scanning the NASA frames, and Ky approved them. Sabik built, ran and checked the pipeline and found and fixed a longitude mistake in the rain frames. Yến set the scope and the story. Every sound complaint that shaped the music (clashing notes, too many notes, crackle, repeated loops) came from people listening.
- **Checks:** the code is covered by automated tests and a round trip (the music is read back to the same levels: 336 of 336 real months). Testing by people with a screen reader and on phones was still to be done when this was written.
- **The idea:** the jukebox that plays Earth data as records, with Side A/B and a "scratched disc" for missing data, is in a team idea note dated 6 Nov; Yến cut the scope on 9 Nov. - **Before the event (Nov 5–13):** we used Claude to study the NASA frames and to write design notes (how to read the colour bars, the data format, the music rules, the tests), one worked example with an illustration, prompts, and a generic accessible page template. Apart from that template, all code, data processing and sound in the product were made on Nov 14–15.
- **Not used:** no AI-generated images, video, voices or sound samples in the product. An AI-made mockup was used only as a look-and-feel reference before the event; the disc art and the console are painted by our code. The music is synthesized live by our code; the background sounds are real field recordings released as CC0 (see `CREDITS.md`). The one illustration in `notes/` has a visible SI label.
- **Marked in metadata:** `provenance` in `docs/data/discs.json`; commits made through Claude Code keep their `Co-Authored-By: Claude` line.
